# translation-meet

"Мікро-Meet" — компактна WebRTC-платформа для дзвінків з клієнтами, яка підтримує до чотирьох учасників, шеринг екрана та живі субтитри українською мовою на базі Deepgram Nova-3 (є перемикач на Nova-2).

## Можливості
- До 4 одночасних учасників у кімнаті (full-mesh WebRTC з perfect negotiation на кожну пару).
- Перемикання між камерою та шерингом екрана, швидке оновлення потоків для всіх учасників.
- Стрімінгова транскрибація української мови через Deepgram Nova-3 (або Nova-2) з відображенням субтитрів і логом розмови.
- Завантаження стенограми розмови у форматі `.txt` (містить тимчасові мітки, імена та текст).
- Кнопка запрошення з автогенерацією посилання на кімнату (включає ім’я співрозмовника).
- Мінімальний бекенд: Express для статики, WebSocket для сигналінгу WebRTC та проксі для Deepgram.

## Необхідні змінні середовища
- `DEEPGRAM_API_KEY` — токен доступу до Deepgram (Nova-2/3 підтримують українську мову та smart-formatting). Без ключа з’єднання для транскрибації не встановиться.
- `DEEPGRAM_MODEL` *(опційно)* — модель Deepgram за замовчуванням (`nova-3` або `nova-2`). Якщо змінну не вказати, застосовується Nova-3.

У локальному середовищі можна експортувати ключ перед запуском:

```bash
export DEEPGRAM_API_KEY=dg_your_token_here
```

## Запуск локально
```bash
npm install
npm start
# В окремих вкладках браузера відкрийте http://localhost:3000 і приєднайтесь до однієї кімнати.
```

> **Порада.** Для продакшену додайте TURN-сервер до `iceServers`, щоб забезпечити стабільну роботу за NAT/фаєрволами.

## Запуск у Docker
```bash
docker build -t translation-meet .
docker run -it --rm -p 3000:3000 \
  -e DEEPGRAM_API_KEY=dg_your_token_here \
  translation-meet
# Відкрийте http://localhost:3000
```

Образ базується на `node:20-bullseye-slim`, встановлює лише production-залежності та стартує сервер командою `npm start`.

## Перемикання моделей Deepgram
- У хедері клієнта доступний селектор **Deepgram Nova-3 / Nova-2**. Nova-3 дає вищу точність (особливо на змішаних англійсько-українських розмовах), Nova-2 — дешевший варіант.
- Обраний варіант зберігається у `localStorage`, передається у запрошеннях і застосовується для всіх учасників, які приєднаються через це посилання.
- Бекенд також може задавати дефолтну модель через `DEEPGRAM_MODEL` (наприклад, щоб примусово використовувати Nova-2 у тестовому середовищі).

## Архітектура
- **Клієнт**: керує локальними медіапотоками, будує WebRTC-з’єднання з кожним учасником, передає аудіо в Deepgram через бекенд і відображає субтитри/лог.
- **Сервер** (`server.js`):
  - Endpoint `/ws` — сигналінг (створення кімнат, обмін SDP/ICE, повідомлення про підключення/відключення).
  - Endpoint `/stt` — WebSocket-проксі, який приймає Opus-чанки з браузера та ретранслює їх у Deepgram Nova-3/Nova-2; отримані часткові/фінальні результати транслюються всім учасникам кімнати.

## Подальші кроки для продакшену
- **TURN-сервер**: додайте власні `iceServers` (coturn, Twilio, LiveKit Cloud тощо).
- **Безпека**: виводьте банер з попередженням про запис/транскрибацію; зберігайте лог розмов на захищених носіях.
- **Масштабування**: для >4 учасників або запису мітів перейдіть на SFU (LiveKit, mediasoup, Janus) чи спеціалізовані платформи.
- **Мульти-мовність**: Nova-2 підтримує кілька мов; за потреби можна додати перемикач та окремі екземпляри під інші моделі.

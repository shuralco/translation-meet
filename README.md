# translation-meet

"Мікро-Meet" — простий WebRTC-MVP для двоосібних відеодзвінків зі спільним екраном і миттєвими субтитрами.

## Можливості
- 1-на-1 відеодзвінок (WebRTC) з perfect negotiation.
- Перемикання між камерою та шерингом екрана.
- Живі субтитри через Web Speech API з відправленням тексту по DataChannel.
- Журнал розмови з можливістю завантажити транскрипт у `.txt`.
- Кнопка швидкого запрошення: копіює посилання на кімнату з мовою/іменем.
- Мінімальний бекенд: Express для статики + WebSocket сигналінг.

## Запуск локально
```bash
npm install
npm start
# Відкрийте дві вкладки http://localhost:3000, вкажіть однаковий room ID і різні імена.
# Можна одразу перейти за посиланням виду http://localhost:3000/?room=demo для автозаповнення поля.
```

> **Примітка.** Для виробничого використання додайте TURN-сервер у `iceServers` і підключіть стрімінговий STT-провайдер.
